# OAC 自然语言数据访问模板

本文件定义上层业务 Skill 委托本体平台数据访问能力时建议提供的信息字段。该模板是通用数据访问模板，不承载具体业务场景规则。

## 模板字段

| 序号 | 字段 | 是否必填 | 填写说明 |
|---:|---|---:|---|
| 1 | schemaRef | 否 | 本体 schema 标识。若不填写，执行脚本从环境变量 `ONTOLOGY_SCHEMA_REF` 获取；若填写，则以传入值为准。 |
| 2 | 操作类型 | 是 | 使用自然语言描述查询动作，例如“查询明细”“查询对象属性”“按关系路径查询”“统计数量”“分组求平均值”。不要求填写 `QUERY`、`ASSOCIATION_QUERY`、`AGGREGATE` 英文枚举。 |
| 3 | 操作选择依据 | 建议 | 说明为什么是明细查询、关联路径查询或聚合统计。 |
| 4 | 查询对象 | 是 | 对象类型、对象别名、对象职责。 |
| 5 | 关系路径 | 条件必填 | 仅关联路径查询必填；无关系路径时写“无”。 |
| 6 | 过滤条件 | 建议 | 字段归属对象、字段名、操作符、取值；时间范围也必须写在过滤条件中。 |
| 7 | 返回字段 | 是 | 返回哪个对象或关系的哪些字段；用户指定字段时不要使用 `*`。 |
| 8 | 聚合要求 | 条件必填 | 仅统计聚合场景填写；包括分组字段、指标函数、指标别名、聚合后过滤条件。 |
| 9 | 排序/限制 | 否 | 排序字段、升降序、最大返回条数。 |
| 10 | 时间要求 | 否 | 时间字段、时间范围、时间口径。本地时间或 UTC 时间只表示时间口径，不能替代过滤条件。 |
| 11 | 扩展说明 | 否 | 只填写已约定扩展参数；无明确约定时写“无”。 |
| 12 | 结果处理 | 否 | 结果为空是否结束、是否保留原始字段、是否需要摘要。 |

## schemaRef 获取规则

`schemaRef` 可以不由用户每次填写。执行 OAC 请求时，如果 OQL JSON 中没有 `schemaRef`，脚本会读取环境变量 `ONTOLOGY_SCHEMA_REF`。如果环境变量也不存在，则返回错误。

优先级：用户显式传入 schemaRef > 环境变量 `ONTOLOGY_SCHEMA_REF` > 报错。

## 操作类型自然语言示例

| 自然语言动作 | 平台路由倾向 |
|---|---|
| 查询对象属性、查询明细、查询指标明细 | QUERY |
| 按关系路径查询、一跳关联查询、多跳路径查询、查询归属关系 | ASSOCIATION_QUERY |
| 统计数量、分组统计、求平均值、求最大值、求最小值 | AGGREGATE |

## extensions.localtime 规则

当时间类型属性的描述为“本地时间”时，可以在扩展说明中要求生成：

```json
"extensions": {
  "localtime": "true"
}
```

当时间类型属性的描述为“UTC 时间”时，可以在扩展说明中要求生成：

```json
"extensions": {
  "localtime": "false"
}
```

`localtime` 只表示时间口径，不表示时间范围。时间范围仍必须进入标准过滤条件。
