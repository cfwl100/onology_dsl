# 获取网元告警

本文件只提供外层 `SKILL.md` 可直接摘录的 Planning 六行输入片段。

本体ID：network@1.0
业务意图：查询指定网元的当前告警，并返回告警对象结构。
业务领域知识：面向 alarm 对象查询网元告警，不用异常事件对象替代告警对象；alarmName 表示告警类型，identifier 表示单条告警标识；网元名称可作为业务过滤条件；默认返回告警的归属、级别、名称、标识、发生时间、清除时间和关联网元信息；空结果表示未发现匹配告警，不自动扩大范围。
流程级定制：使用默认流程 S1 -> S2 -> S3 -> S6；无其他流程覆盖。
步骤级定制：S1 检索网元到告警相关子图；S2 基于子图规划告警查询任务；S3 返回告警 objects 与 relationships；S6 汇总告警数量、告警摘要、缺失信息和下一步建议。
缺失信息：缺少网元名称时填写“缺少网元名称”；否则填写无。
