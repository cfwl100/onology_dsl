# 获取传播知识

本文件只提供外层 `SKILL.md` 可直接摘录的 Planning 六行输入片段。

本体ID：network@1.0
业务意图：获取指定告警或网元相关的传播知识，用于辅助传播分析。
业务领域知识：传播知识用于说明告警、网元、传播关系和传播特征之间的业务含义；传播知识只描述可能的传播模式，不直接代表实例层证据；alarmName 表示告警类型，identifier 表示告警标识；最终是否存在传播证据，需要结合实例查询结果判断。
流程级定制：使用默认流程 S1 -> S2 -> S3 -> S6。
步骤级定制：S1 检索传播知识相关子图；S2 基于子图规划传播知识查询任务；S3 返回传播知识对象结构；S6 汇总传播说明、缺失信息和后续建议。
缺失信息：缺少告警、网元或传播分析目标时填写对应缺失项；否则填写无。
