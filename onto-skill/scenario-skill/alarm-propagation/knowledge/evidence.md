# 传播证据验证知识片段

本文供外层 `SKILL.md` 摘录并组装给 `Ontology-based-planning-skill`。

## 本体ID

```text
network@1.0
```

## 业务意图

```text
验证起始网元 ${neName} 在 ${directions} 上是否存在名称属于 ${alarmNames} 的活动告警，并返回相关网元和告警对象结构。
```

## 业务领域知识

### 场景知识

传播证据验证用于检查传播方向上的实例数据，不等同于传播关系定义查询。

### 方向知识

支持同站点、对端网元、业务路径三个方向。多方向时，每个方向独立处理。

### 变量知识

`neName` 表示起始网元名称；`alarmNames` 表示告警类型列表；长列表必须变量化。

### 规则知识

子图检索、任务规划和数据查询均以本体子图返回的对象、字段和关系为准；不得编造字段、对象或路径。

### 返回要求

返回网元对象、告警对象以及二者关系；汇总时说明是否发现匹配告警、数量、摘要和缺失信息。

### 失败策略

缺少方向、起始网元或告警类型列表时填写缺失信息；空结果表示未发现匹配告警，不自动扩大范围。

## 流程级定制

```text
使用默认流程；不执行 S4/S5 Function；多方向时每个方向独立处理；空结果视为有效结果。
```

## 步骤级定制

```text
S1 使用方向相关子图检索规则；S2 基于子图规划传播证据任务；S3 返回网元和告警对象结构；S6 按方向汇总结果。
```

## 缺失信息

```text
如果缺少方向、起始网元名称或告警类型列表，填写对应缺失项；否则填写无。
```
