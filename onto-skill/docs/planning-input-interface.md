# Ontology-based-planning-skill 对外输入接口

本文档定义业务定制 Skill 传给 Ontology-based-planning-skill 的顶层输入约束。

## 顶层输入

业务定制 Skill 只输出以下 6 行：

```text
本体ID：<公共本体ID>
业务意图：<详细自然语言问题>
业务领域知识：<本次执行需要的场景知识、业务规则、子图检索规则、任务规划规则、查询规则、Function 规则、返回要求和失败策略；没有则写无>
流程级定制：<只填写相对默认流程的覆盖项；无覆盖写“使用默认流程”>
步骤级定制：<只填写相对默认步骤模板的业务增量规则；无增量写“使用默认步骤模板”>
缺失信息：<没有则写无>
```

## 约束

- 字段名保持一致。
- 本体ID只填写一个公共本体ID。
- 业务意图填写业务侧改写后的完整任务。
- 业务领域知识承载本次任务所需的全部业务上下文。
- 流程级定制只描述默认流程的差异。
- 步骤级定制只描述每个步骤的业务增量。
- 缺失信息没有时写无。

## 默认步骤

- S1：子图检索。
- S2：基于本体子图的任务规划。
- S3：OAC 数据访问。
- S4：Function 发现。
- S5：Function 执行。
- S6：汇总。

默认流程为 S1 -> S2 -> S3 -> S6。

## 运行时约束

这些约束由产品文档保证。Ontology-based-planning-skill 运行时直接读取 6 行原文生成 executionPlan，不再重复构造字段映射对象、planningContext、inputGate 或 stepRuleMap。
