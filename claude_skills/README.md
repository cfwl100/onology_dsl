# OQL Claude Skills

按 OQL 规范拆分的 11 个 operation skill：

- `oql-query`: `QUERY` 专用 DSL 生成约束（见 `oql-query/SKILL.md`）。
- `oql-multi-object-query`: `MULTI_OBJECT_QUERY` 专用 DSL 生成约束（见 `oql-multi-object-query/SKILL.md`）。
- `oql-aggregate`: `AGGREGATE` 专用 DSL 生成约束（见 `oql-aggregate/SKILL.md`）。
- `oql-association-query`: `ASSOCIATION_QUERY` 专用 DSL 生成约束（见 `oql-association-query/SKILL.md`）。
- `oql-list-linked-objects`: `LIST_LINKED_OBJECTS` 专用 DSL 生成约束（见 `oql-list-linked-objects/SKILL.md`）。
- `oql-get-linked-object`: `GET_LINKED_OBJECT` 专用 DSL 生成约束（见 `oql-get-linked-object/SKILL.md`）。
- `oql-create`: `CREATE` 专用 DSL 生成约束（见 `oql-create/SKILL.md`）。
- `oql-update`: `UPDATE` 专用 DSL 生成约束（见 `oql-update/SKILL.md`）。
- `oql-delete`: `DELETE` 专用 DSL 生成约束（见 `oql-delete/SKILL.md`）。
- `oql-upsert`: `UPSERT` 专用 DSL 生成约束（见 `oql-upsert/SKILL.md`）。
- `oql-batch`: `BATCH` 专用 DSL 生成约束（见 `oql-batch/SKILL.md`）。
